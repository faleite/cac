# prompt
Me ajude a criar um prompt para pedir para gerar um design web responsivo para acesso no telemovel para um projeto de um controle de atividades, onde o usuario é um  entregador de pacotes dos correios CTT. para isso ele possui uma carrinha e recebe uma quantidades de pacotes para fazer a entrega e ao final do dia ele enviar um relatorio via whatsapp para a empresa contendo os seguintes dados:

```txt
*_10/08/2026_*

*Início* 
Nome: *Fabricio Leite* 
Matrícula: *BI-04-NH* 
Km iniciais: *73136*
Giro: *2825H* 
Qtd Objectos: *159* 
Qtd Recolhas: *1*    

*Final* 
Nome: *Fabrício Leite* 
Matrícula: *BI-04-NH* 
Km Finais: *73207*
Giro: *2825H* 
Qtd Objectos: *159*
Qtd Recolhas: *1* 
Qtd Avisados: *1*
Qtd Retornos: *3* 
Qtd End. Insuf.: ** 
Qtd Recusados: **
Qtd desc morada.: *1*

```
A aplicacao web fara o cadastro do usuario, bem como coletara sua atividade diaria, onde mantera um banco de dados com suas informacoes e os dados da atividade diaria.

Esta aplicacao tera dashboard diario e mensal sobre as metricas de entregas e kilometragem do veiculo. Tambem quando o usuario preencher o controle diario ao final sera gerado um arquivo txt com os dados que a aplicacao facilitar o compartilhamento para enviar a uma conversa no whatsapp.
